# 论文写作标准（AI 顶会 + CNS 级）— 审稿判据 v2

本文件定义论文必须满足的写作标准。对抗审稿轮次以此为准绳：审稿人按这里
的每一项检查，不是凭感觉。

标准基准（官方，非经验之谈）：

- Nature Article 格式指南（Formatting Guide to Authors / Nature Nanotechnology
  ForAuthors.pdf）：摘要 ≤150 词、无引用无缩写；引言 ≤500 词；Results 带
  子标题（≤60 字符、不编号、无二级子标题）；Discussion 无子标题；Methods
  后置带子标题；4-6 display items；refs ≤50；正文 2000-3000 词。
- Nature Communications：摘要 150 词或更少，末句以 "Here we show"（中文：
  「本文表明/我们表明」）开头收束主结果；缩写/引用禁用。
- NeurIPS 2025 官方模板与 FAQ：摘要 ≤200 词单段；main text 9 页；APA 引用；
  匿名；checklist 要求 claims/limitations/reproducibility/statistical
  significance 显式回应。
- NeurIPS Checklist Q1：摘要与引言中的主张必须精确对应实验结果的泛化范围，
  假设与局限必须显式陈述。

## 1. 摘要架构（六段式，150-200 词，单段，无引用无公式无编号）

1. **背景** —— 领域共识一句话（引用可含可不含，preprint 不含）。
2. **缺口** —— 现有方法具体做不到什么（一句，命名具体缺陷）。
3. **方法** —— 一个动词句：提出 / 证明 / 引入什么（"Here we show"）。
4. **结果** —— 关键数字 + 方向（不只说"更好"，说"从 X 到 Y"）。
5. **边界** —— 适用域限制一句（"在该 regime 下"，不吞吞吐吐）。
6. **意义** —— 为什么有人在乎（方法论贡献，不是自夸）。

禁止：引用、公式、编号、"本文结构如下"、first/best 类无定义绝对词。
末句用 "Here we show ... / We show that ..." 收束（Nature 体例）。

## 2. CNS 格式骨架（逐条对照官方）

| 维度 | preprint（旧稿） | CNS 级（目标） |
|---|---|---|
| 摘要 | 长段 200-300 词 | **150-200 词**，六段式，无引用，末句 Here we show |
| 引言 | 历史综述 4-6 段 | **≤2 段 / ≤500 词**：问题在首句，主结果在首屏，无历史，无子标题 |
| 相关工作 | 独立节 | **压缩成一段**带引用，放引言末或方法前，不独立成节 |
| 结构 | 连续小节 | 引言（无标题）→ 结果（3-4 个带小标题结果节，子标题 ≤60 字符不编号）→ 讨论（无子标题）→ 方法（后置，带子标题） |
| 图 | 装饰 | **高信息密度 + 自足 caption**（读图即懂，不查正文），4-6 display items |
| 数字 | 分散 | 每个数字可复现、每个声明有对应证据（checklist 精神）；**统计口径必报**（n、CI、判定规则） |
| 语言 | 平铺 | 每句有信息，无填充句 |
| 参考文献 | 不拘 | **≤50；只引一手/必要**；每个被点名的工作有对应条目 |

## 3. 主结果前置（顶刊阅读流）

- 主定理/主结果在引言后**立即**出现（Results 第一节就是最大发现，不是铺垫）。
- 每节开头一句"本节答什么"；每节结尾一句"得到什么、下节要什么"。
- 主结果 ≤ 3 个，每个带一句人话解读（不用黑话）。
- 边界/局限：单独成段，明说不喧宾。

## 4. 可复现性（NeurIPS checklist 精神）

- 每个实验：数据来源、协议、seed、代码位置（commit hash）可定位。
- 统计显著性：主声称必须带 n + 置信区间/误差棒 + 判定规则；判定规则须
  写于实验之前（预注册），不许事后选择等价界。
- 负结果如实入文（本文的"分形无优势"是主结果之一，不是脚注）。
- 假设与声称分离："机制可行" vs "结构更优" 是两个断言，分别给证据。
- 复现信息落盘：trace 文件路径、大小、md5、最后写入时间、运行轮数。

## 5. 审稿人逐条检查表

- [ ] 摘要 150-200 词单段？六段齐全？独立朗读自足？无引用无公式无 first/best？
     末句 Here we show 收束？
- [ ] 引言 ≤2 段 ≤500 词、问题在首句、主结果首屏、无子标题、无历史综述？
- [ ] 相关工作总结成一段（不独立成节）？
- [ ] Results 子标题 ≤60 字符、不编号、无二级子标题；Discussion 无子标题；
     Methods 后置带子标题？
- [ ] 图/表 caption 自足（读图即懂）？display items 4-6？
- [ ] 每个数字有出处/可复现命令？主声称带 n + CI + 判定规则？
- [ ] 边界句单独成段？
- [ ] 声称与证据匹配（不强、不弱）？checklist 的 claims 与 limitations 显式？
- [ ] 负结果如实（不藏、不洗）？
- [ ] 参考文献 ≤50 且全部真实可核？
