# 论文写作标准（AI 顶会 + CNS 级）— 审稿判据

本文件定义论文必须满足的写作标准。对抗审稿轮次以此为准绳：审稿人按这里
的每一项检查，不是凭感觉。

## 1. 摘要架构（AI 顶会标准，六段式）

摘要必须独立成文（单独朗读一遍应自足），含且仅含六段：

1. **背景** —— 领域共识一句话（引用可含可不含，preprint 不含）。
2. **缺口** —— 现有方法具体做不到什么（一句，命名具体缺陷）。
3. **方法** —— 一个动词句：提出 / 证明 / 引入什么。
4. **结果** —— 关键数字 + 方向（不只说"更好"，说"从 X 到 Y"）。
5. **边界** —— 适用域限制一句（"在该 regime 下"，不吞吞吐吐）。
6. **意义** —— 为什么有人在乎（方法论贡献，不是自夸）。

禁止：引用、公式、编号、"本文结构如下"。

## 2. CNS 格式骨架

CNS（Nature/Science/Cell 体）与 preprint 的差异，逐条：

| 维度 | preprint（旧稿） | CNS 级（目标） |
|---|---|---|
| 摘要 | 长段 200-300 词 | **150-200 词**，六段式，无引用 |
| 引言 | 历史综述 4-6 段 | **≤2 段**：问题在首句，主结果在首屏，无历史 |
| 相关工作 | 独立节 | **压缩成一段**带引用，放在方法前或脚注 |
| 结构 | 连续小节 | 引言 → 结果（3-4 个带小标题的结果节）→ 方法（后置）→ 讨论 |
| 图 | 装饰 | **高信息密度 + 自足 caption**（读图即懂，不查正文） |
| 数字 | 分散 | 每个数字可复现、每个声明有对应证据（checklist 精神） |
| 语言 | 平铺 | 每句有信息，无填充句 |

## 3. 主结果前置（顶刊阅读流）

- 主定理/主结果在引言后**立即**出现（不是第 5 节）。
- 每节开头一句"本节答什么"；每节结尾一句"得到什么、下节要什么"。
- 主结果 ≤ 3 个，每个带一句人话解读（不用黑话）。
- 边界/局限：单独成段，明说不喧宾。

## 4. 可复现性（NeurIPS checklist 精神）

- 每个实验：数据来源、协议、seed、代码位置可定位。
- 负结果如实入文（本文的"分形无优势"是主结果之一，不是脚注）。
- 假设与声称分离："机制可行" vs "结构更优" 是两个断言，分别给证据。

## 5. 审稿人逐条检查表

- [ ] 摘要六段齐全？独立朗读自足？无引用无公式？
- [ ] 引言 ≤2 段、主结果首屏？
- [ ] 相关工作总结成一段？
- [ ] 图 caption 自足？
- [ ] 每个数字有出处/可复现命令？
- [ ] 边界句单独成段？
- [ ] 声称与证据匹配（不强、不弱）？
- [ ] 负结果如实（不藏、不洗）？
