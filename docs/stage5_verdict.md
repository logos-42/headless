## 1. 一句话

> **接线做完了,互补性没有出现。** 四条 GVF **不是彼此的拷贝**(误差相关 0.01–0.11),
> 但**也没有一条是有用的检测器**(单条 AUC 多在 0.50 附近,最好 0.65)。
> 而且`z_bad=2.0` 这个阈值在稳态下**几乎从不触发** ⇒ **证据库在三个 seed 上一次都没投过 `bad`**。
> ⇒ 阶段五的机制是**接线正确但信号为空**,不是"证据不互补"。

## 2. 互补性度量(3 seed,4 个标签各算一次)

| 标签 | 单条 AUC(均值) | `any` 并集 | `consensus` 并集 | 最好单条 | complementarity | disagreement |
|:--|:--|--:|--:|--:|--:|--:|
| `prediction` | predi 0.572 / rewar 0.615 / trans 0.399 / regim 0.540 | 0.579 | 0.613 | 0.620 | **−0.0419** | 0.243 |
| `reward` | predi 0.559 / rewar 0.544 / trans 0.480 / regim 0.548 | 0.528 | 0.572 | 0.564 | **−0.0363** | 0.194 |
| `transition` | predi 0.342 / rewar 0.383 / trans **0.650** / regim 0.464 | 0.412 | 0.381 | 0.650 | **−0.2378** | 0.191 |
| `regime` | predi 0.527 / rewar 0.515 / trans 0.488 / regim 0.566 | 0.513 | 0.560 | 0.566 | **−0.0525** | 0.194 |

**`complementarity` 范围 −0.3248 … −0.0145(均值 −0.0921)—— 全部为负。**

### 2.1 ★ 但这个数**不能**证明"不互补"(必须先说清楚)

两个并集规则给出的大小关系是**反直觉**的:`any`(析取)0.508 **低于**
`consensus`(合取)0.560。析取本该比合取检出更多。

原因是**正例太稀疏**:稳态下 `z ≈ 1`,而 `z_bad = 2.0` 的触发极少 ⇒
并集标志几乎恒为 0 ⇒ AUC 被位置抖动(`+1e-6·i`)主导 ⇒ **那个数值不可解释**。

修这个的代价:改阈值会让并集有正例,但阈值又与稳态 z 的尺度绑定(见 §4)。
**所以本批真正可信的负面事实是 §3 那两条,不是 complementarity 的具体数值。**

## 3. 两条可信的负面事实

### 3.1 它们**不是**彼此的拷贝

| 对 | corr_err(3 seed 平均) |
|:--|--:|
| `prediction~reward` | +0.013 |
| `prediction~transition` | +0.028 |
| `prediction~regime` | +0.113 |
| `reward~transition` | +0.018 |
| **`reward~regime`** | **+0.603** |
| `transition~regime` | +0.025 |

⇒ 六对里五对**几乎不相关**,说明这四条确实在测不同的东西。
**"冗余"这个假设被否掉了** —— 它们不是同一序列的四种写法。
(唯一高相关的一对是 `reward~regime`,符合直觉:我选的 `regime` cumulant 是"本回合结束",
它与"拿到奖励"在稀疏奖励世界里天然同步。这是**我的 cumulant 选择**造成的,不是机制问题。)

### 3.2 但**没有一条是有用的检测器**,而且证据库**从未开火**

- 单条 AUC:最低 0.225,最高 0.754,但 16 个读数里多数落在 0.50±0.06
  ⇒ 平均而言不比抛硬币好多少
- **`bad票累计 = 0`** —— 三个 seed 全是 0
  ⇒ `EvidenceBank.support()` 返回 `bad` 的次数是 **0**
  ⇒ 阶段五那条 `GVFBank → 证据 → 三态` 的链**接通了但从未被触发过**

**这一条是本批最重要的读数。** 一个"接通了但从不动作"的机制,从日志上看起来
和"机制没接"完全一样 —— 分辨它们要靠这个计数器,而不是靠"三态输出正常"。

## 4. 根因(两条,都在我这边)

1. **阈值与稳态尺度不匹配。** `z_bad = 2.0` 是照搬 A 类的口径,但 A 类测的是
   **regime 切换前后的对比**,而这里是**稳态运行中**的逐 step 读数 ——
   稳态下 `err_ema / err_ref` 天然收敛到 ~1。阈值 2.0 因此永远够不着。
   ★ 这是**同一类错误第三次出现**:阈值必须与它所处的状态空间/时间窗口匹配
   (前两次:`β_o` 的距离阈值落进离散距离的空隙、探针打在稳态而非切换点)。
2. **我挑的四个 cumulant 可检测性太弱。** "有 option 在跑 / 即时奖励 / 状态没变 /
   回合结束"这四个里,没有一个是**变化敏感**的信号。它们都近似平稳
   ⇒ 预测误差近常数 ⇒ z 近常数 ⇒ 没有可比对的"变化"可用。

## 5. 建立的资产(即便结论是负的)

1. **`EvidenceBank` 是一个真的证据库**,不是平均器:
   - `support()` 的返回值里**没有任何跨 GVF 的标量均值**,只有**引用清单**
     (`bad` / `healthy` / `missing` + 每条来源)
   - **缺席显式**:覆盖不足 / 陈旧 / 跨 regime 的证据进 `missing`,
     **不按 0 平均进去**(旧实现正是这样让"未知"伪装成"好")
   - **动力学证据只能降级**:`role == "dynamics"` 可以投 `bad`,
     **永远不能**把状态升成 `good`(反熟悉度约束,硬编码不是可调项)
2. **单测 20/20**,含四条不变量:
   - ① 不许平均(符号相反的极端组合:输出不是均值,引用清单非空)
   - ② 缺席 ≠ 健康(全部不可用 ⇒ `unknown`,**不是** `good`)
   - ③ 动力学不能升级(动力学全 healthy + outcome 缺失 ⇒ `unknown`;反面对照才 `good`)
   - ④ 每条证据用它**自己**的尺度归一(换一条的尺度不影响另一条)
3. **`rr_evidence=False` 时旧行为逐位不变** —— `test_rr_agent` / `test_self_calib` /
   `bench_rr_sentinel` 全过。
4. **修了一个真实的 TD 语义 bug 类**:接线时用 `phi=v0, phi_next=vec(s')`,
   而不是像 `oak_proposer.py:338` 那样两个都传当前 vec
   (两个都传当前 vec ⇒ `v_next == v` ⇒ TD 的 `gamma·v_next` 项与 `v` 抵消,
   学的是"瞬时误差"不是值)。

## 6. 下一步(若要继续阶段五)

1. **先挑出"变化敏感"的 cumulant**,而不是随手拿四个可观测事实。
   候选:`option 的预期时长 vs 实际时长`(时序意外)、`p̂(s'|s,a)` 的漂移、
   `本步奖励 vs 该状态的历史平均`(结果意外)。**每个都要能说清"它变了意味着什么"。**
2. **阈值按"切换点"标定**,不按稳态标定 —— 与 A 类同一条纪律。
   并加一条**触发率闸门**:`bad` 票为 0 的批**直接判为"机制未工作"**,
   不许写"证据表明没有变化"。
3. 只有在 ① ② 之后,`complementarity` 的数字才有意义。
