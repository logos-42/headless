## 1. 现有 `efficiency_report` 的三个缺陷(逐条)

```python
final = max(a for _, a in cur)     # ← 缺陷①
tgt   = final * th
hit   = next((st for st, a in cur if a >= tgt), None)
```

**① 用自己的峰值当 100% 基准 ⇒ 遮盖"学不到"。**
"学得慢但最终很高"与"学得快但最终很低"会得到**相同的相对达标步数**。
跨臂比较时会把一个**根本没学会**的臂报成"效率高"。
⇒ 必须补**绝对口径**:阈值取该域的可达上限(已测 3/6/12 域 = 0.9159/0.8065/0.6638),
**达不到就记 `None`,不许用峰值回填**。

**② 达标步数是轮内步号 ⇒ 跨臂不可比。**
不同臂每轮的预算可能不同。⇒ 同时记**轮内步数**与**该轮结束时已累计的总更新数**。

**③ 只留最后一次访问 ⇒ 丢掉"复用"。**
`:1063` 覆盖式写入,前几次访问的曲线全丢。而"**重复遇到同一域时是否学得更快**"
正是**知识复用**的可测形式(leo 阶段六的第一个指标)。
⇒ 改成**逐次访问都留**(`curves[dd]` → `visits[dd] = [curve1, curve2, ...]`)。

## 2. 指标族(三个,互相独立,都报)

### A. 绝对达标步数 `steps_to_abs`
```
对域 d 的**第 k 次访问**:
    target = 该域可达上限 × θ        (θ ∈ {0.5, 0.9})
    ★ 若**该次访问的起点** acc[start] ≥ target  ⇒ 记 "already"(不是 0, 也不许算 1)
    否则 steps_to_abs[d][k][θ] = 该次访问中首次达到 target 的**轮内步数**
    达不到 ⇒ None                    ← 不许回填, None 是有信息量的值
```
可达上限用**独立于臂**的常数(预先测出的 oracle 上限),不用臂自己的峰值。

> **2026-09-30 修订(冒烟测发现, 在任何真实批跑之前)**:
> 初版**没有区分"起点已超阈"**。在 `revisit` 流下, 重遇到某个域时模型**起点已经会了**,
> 于是每个域每次访问都报 **1 步达标**, 复用增益**机械归零**。
> 冒烟测实测: `steps_to_abs` 全部 = 1、`revisit_gain` 全部 = 0.0 —— 那是**伪零**,
> 与 L4 的"方差伪影"是同一类(度量被打到地板, 而不是机制不工作)。
> 故引入第三态 `"already"`, 并把**复用/保留**改由下面 C' 承担。

### B. 早期斜率 `slope_early`
```
slope_early[d][k] = (acc@K − acc@start) / (K 步)
```
"每单位更新换来多少精度" —— "更新效率"的字面含义。

### C. 访问内增益 `within_gain`
```
within_gain[d][k] = acc[end] − acc[start]
```
**不受阈值影响, 永远有定义** —— 阈值口径饱和时的兜底量。

### C'. ★★ 保留增益 `retention_gain`(**本规格的核心量**)
```
retention_gain[d] = mean(start_level[d][k] for k ≥ 2) − start_level[d][1]
```
`start_level[d][k]` = 第 k 次访问**第一个采样点**的准确率。

- `> 0` ⇒ 后面几次**起点更高** ⇒ **记住了**(保留 / 复用)
- `≈ 0` ⇒ 每次从零开始 ⇒ **没有保留**
- `< 0` ⇒ 起点更低 ⇒ 干扰

★ **为什么它取代了 `steps_to_abs` 当主判据**: 在"重遇到就起点已会"的流下,
达标步数被 `"already"` 吃满(`_already_ratio` 实测 0.58–0.75), 没有分辨力;
而**起点水平**同时绕过阈值饱和**与**末态精度饱和(后者在修好的流上已经测不出差异)。
它也更接近"持续学习有没有用"的直接问法。

★ 判据必须**允许"没有保留"**。负结果照样写下来。

> ### ⚠⚠ 2026-09-30 二次修订:`retention_gain` **作为主判据被推翻**
> (LMEFF 批跑完、写结论之前;详见 `docs/lmeff_verdict.md` §1)
>
> 它的 `+0.427`(6/6 域同向、自助法 CI 不含 0)**是 `start_level[1]` 单点锚的噪声**。
> 换锚点后:
>
> | 锚点口径 | Δ(replay−naive) |
> |:--|--:|
> | 用第 1 次访问当锚(原) | **+0.4270** |
> | 用前 3 次的中位数当锚 | +0.0807 |
> | 对访问序回归(**不用锚**) | **+0.0010** |
>
> 根因: 同一个域同一个臂, 三个 seed 的 `start_level[1]` 从 **0.011 到 0.889**。
> "6/6 域同向"是这个噪声被系统性放大的结果。
>
> **⇒ 新的主判据改为无锚点的两个量**:
> 1. **`already_ratio`**: 重访**第一个采样点**就 ≥ 阈值 的比例(约 300 次访问的均值)
> 2. **`start_level` 的绝对水平**: 前 10 次 vs 末 30 次
>
> ★ **通则(写进纪律)**: 任何靠**单个观测**当锚的统计量, 都必须在**换锚点后**重算一遍。
> "换锚点后消失"与"从一开始就没测到"是**两个不同结论**, 前者要当缺陷写进论文。

## 3. 记录格式(写进 JSON,不是只打印)

```json
"efficiency": {
  "steps_to_abs": {"D0": {"1": {"50": 34, "90": null}, "2": {"50": 12, "90": 40}}, ...},
  "slope_early":  {"D0": {"1": 0.0021, "2": 0.0058}, ...},
  "revisit_gain": {"D0": {"90": 28}, "D3": {"90": null}},
  "n_visits":     {"D0": 3, "D3": 1},
  "reachable_max": 0.8065,
  "theta": [0.5, 0.9],
  "K_slope": 50
}
```
`visits` 原始轨迹也一并写(`{"D0": [curve1, curve2, ...]}`),否则事后无法复核。

## 4. 判据(事前写死)

| 项 | 判据 |
|:--|:--|
| 填充闸门 | `n_visits` 全部 ≥ 1 且 `steps_to_abs` **非全空**,否则判 **"指标未采集成功"**(不是"效率为 0") |
| 覆盖率 | 报 `steps_to_abs` 里 `None` 的比例 —— 太高说明阈值取错(参照:阈值必须与该域可达上限匹配) |
| 复用 | `mean(revisit_gain) > 0` 且自助法区间下界 > 0 ⇒ 有复用;否则**照实写"无复用"** |
| 对照 | 必须在**同一批、同一流**下比 ≥2 个臂;单臂数字不构成结论 |

## 5. 明确不做

- 不改 `--trace-every` 的默认值(默认仍 0 ⇒ **旧结果逐位不变**)
- 不把 `efficiency` 接进任何决策(它是**报告层**指标,不是控制信号)
- 不扫 `K_slope` / `θ`
- 不碰 LM4 主链的模型/数据侧
- 不在本阶段做完整的学习曲线可视化

## 6. 验收

1. `--trace-every=0` 时输出与旧版**逐位相同**
2. `--trace-every=N` 时 `efficiency` 的五个子字段都非空,且 `n_visits` 与实际访问次数一致
3. `reachable_max` 与传入的常数一致(不是臂自己的 max)
4. 单元测试: 用**人造曲线**验证
   - ① 学不到(全程低于阈值) ⇒ `steps_to_abs` 为 `None` 而**不是**回填峰值
   - ② 两次访问,第二次更快 ⇒ `revisit_gain > 0`
   - ③ 两次访问一样 ⇒ `revisit_gain == 0`
5. 跑一批真实数据,输出三组数字(**无论复用有无都照实写**)
