# 阶段四 A:A 类稠密 cumulant 的否证实验

**日期**: 2026-09-27
**结论先行**: **A 类在本测试台上不可作为主任务 cumulant,也不宜作为风险通道 ——
三个候选全部退化为同一个「新颖度」计数。按 leo 的 §6,只能标记为辅助知识;
按 §5,不进入多 GVF 合并。**
**这不是调参能修的**: 根因是 `KeyDoorMDP` 的动力学**完全确定性**。

| 2 | 不把"稳定但错误"误判为 good | **结构性通过** —— A 只降级不升级(设计约束),`④/⑤` 均过 |

## 二、否证实验的实际输出(3 seeds 前的单 seed 决定性读数)

    ⑨ [a1]  chaos 6/9   harm 6/9     ← 对两个镜像故障反应**逐位相同**
    ⑨ [a2]  chaos 5/9   harm 5/9     ← 同
    ⑨ [a3]  chaos 0/9   harm 0/9     ← 方向 bug 未修(修后见下)

**修好 A3 方向后重跑整台**:

    ⑨ [a3]  chaos 3/9   harm 3/9     ← 修后**仍是逐位相同**, 与 a1/a2 同一签名

⇒ 三个候选的最终形态是**同一个失败模式**: 对两个镜像故障的触发次数
完全相同。这不是巧合, 是 §4.2 那个结构性坍缩的直接后果。

leo 的问题是: A 能不能分清「不稳定」(chaos) 和「稳定但错误」(harm)？
**答案比"分不清"更糟: A1/A2 对两者的触发次数一模一样。** 这意味着它们
既不是"被稳定但错误骗了",也不是"专门测不稳定" —— 它们测的是别的东西。

## 三、决定性补充探针:它在**无故障**场景误报多少

`tests/probe_dyn_fp.py`,normal 是**无故障**场景,触发的就是误报:

    臂      normal    inert    harm    chaos
    A1       3/3      9/6      9/6     9/6
    A2       2/3      7/6      7/6     7/6
    A3       0/3      0/6      0/6     0/6      ← 方向 bug 未修
    A3(修后) 3/3      6/6      6/6     6/6      ← 修后**同构于 A1/A2**

**A1 在健康场景的误报率(3/3)与故障场景(9/6)同量级。** 它没有场景分辨力。
A3 修好方向后**也没了分辨力** —— 三个语义不同的候选最终表现完全一致,
这正是 §4.2 那个结构性原因的样子。

## 四、两个真 bug(都在下结论前被抓到)

### 4.1 A3 的**方向写反**

通道约定是「越大越压力」,而 A3 的代码 `return 1.0 - 熵/归一化` 返回的
是**熟悉度**。于是读数恒为 1.000、基线恒 1.000、判据永不触发。
**"通道方向写反"的典型指纹: 指标看起来在动(恒 1.000 也是个值),
但基线与判据读的是相反的量。** 已修(返回 `熵/归一化`)。

### 4.2 ★ 真正的根因:**测试台是确定性 MDP,A 类必然退化为新颖度**

直接读 `hibs_lnn/skill_mdp.py:91` 的 `step()`: 全部是
`self.pos = max(0, self.pos - 1)` 这类**无随机源**的确定性转移。
测量印证 —— 实跑后统计所有 `n ≥ 2` 的 `(s,a)`:

    A1 / A2 / A3:  n>=2 的最大熵 = 0.000000   (逐位精确零)

于是在这个环境里:

    A1 转移不确定性   —— 熵恒 0, 唯一非零分支是 `n<2` -> **纯新颖度**
    A2 转移预测误差   —— 一旦 n>=2, p(实际后继)=1, 误差恒 0 -> **纯新颖度**
    A3 稳定区域       —— 熵恒 0 -> 修好方向后也**只在全新状态**上非零 -> 同

**三个语义完全不同的候选,在确定性动力学下坍缩成同一个信号 =
「这个 (s,a) 我见过几次」。** 这正是 leo 预判的失效模式
(「它可能只测熟悉度,而不是任务价值」) —— 现在它被**测量**出来了,
而且比预判更强: 不是"可能只测熟悉度",是"**在本环境下必然是**只测熟悉度"。

这解释了一切观测: 为什么 A1/A2 在四个场景的触发率同量级(新颖度在各场景
都差不多)、为什么 A3 完全无反应(熵恒 0)、为什么它对稳定但错误无感
(新颖度根本不问"对不对",只问"见过没")。

## 五、结论与下一步(严格按 leo 的 §5/§6)

1. **A 类不作为主任务 cumulant。** §6 第 6 条("至少一个冷启动指标优于 sparse-GVF")
   失败; §6 末句适用: 只能标记为辅助知识。
2. **不进入阶段五(多 GVF 合并)。** §5 的进入条件是"A 类通过反熟悉度实验",
   它没有通过。
3. **修的方向不是换 cumulant,是先换测试台。** 要让 A 类**可测**,
   环境必须满足: **动力学有真实随机性,且即使在计数饱和之后,
   "可预测"与"不可预测"仍然可分**。否则 A1/A2/A3 在数学上就退化为同一个量,
   再怎么设计判据也测不出差别。
   —— 这是本轮最可操作的一条产出: **A 类的可测性前提是一个随机动力学测试台。**
4. **未完成项(明写)**: 门 4(regime shift 后重新进入 unknown)本轮未单独测量;
   所有读数均为 **1 seed**,未有 3-seed 确认 —— 但因为失效是"精确 0 熵"这种
   **结构性**的,多 seed 不会改变结论方向。

## 六、方法学收获(已记入 skill)

- **报告出现"不可能的数值"时先怀疑算它的人**: fallback > 1(实测 6.827)、
  基线逐位恒定(1.000)、触发次数在两个对照场景里**逐位相同** —— 三种都是
  "评测代码自己有 bug"的指纹,不是机制的性质。
- **否证实验必须包含一个"健康对照"**: 只在故障场景测误报,永远分不清
  "检测器灵敏"和"检测器乱响"。normal 场景的误报率是必备的第三个数。
- **语义不同的候选可能在特定动力学下是同一个量**: 设计多个 cumulant 时,
  必须先确认它们在目标环境的动力学下**不是代数退化的**,
  否则整个对照矩阵测的是一个东西的三份拷贝。
