# OaK 结构件在 lm4/lm5 上的正式对照结果

**结论(诚实,负面)**:加入 OaK 的 **Options / 时间抽象** 在 lm4 与 lm5 上
**都显著降低了在线准确率**;机制确实生效,不是"没触发"。

## 2. regime shift(E11 单次漂移 / E12 反复漂移)

机制:第 K 轮起**置换「动作索引 → 物理细区间」的映射**,使 `T(s,a)` 本身改变。
固定域序下 `T(s,a)` 不变,学到的知识不会被挑战 —— 那测不出 OaK
「适应持续变化的动力学」的主张。

| 实验 | 指标 | 有 Options | 无 Options | Δ | p |
|:--|:--|:--|:--|:--|:--|
| E11 单次 @40 (n=3) | 最差遗忘界 | 0.3725 ± 0.0985 | **0.2942 ± 0.0471** | +0.0782 | 0.215 |
| E11 单次 @40 (n=3) | 最终 acc | 0.7657 ± 0.0133 | **0.7880 ± 0.0097** | −0.0223 | — |
| E12 反复 @30/25 (n=3) | 最差遗忘界 | 0.4253 ± 0.0553 | **0.3279 ± 0.1567** | +0.0974 | 0.310 |
| E12 反复 @30/25 (n=3) | 最终 acc | 0.7624 ± 0.0013 | **0.7831 ± 0.0168** | −0.0207 | — |

**方向与主结论一致(Options 更差),但 n=3 不显著。** 漂移场景**没有**
把 Options 变成有利 —— 这是对"Options 在非平稳环境下才显价值"这一假设的
一个**反证据**(样本量有限,标注为初步)。

### ★ 记账:一个统计 bug(已修,重跑中)

早先 `OAKProposer.stats()` 把 `alpha_std` 写在**会覆盖** `base` 真统计的键上,
而那个值取自 `know.plasticity` —— **一个从未被 `observe_plasticity` 更新的对象**。
后果:四个算法在 JSON 里报出**同一个** `alpha_std = 2.78e-17`,看起来像
"算法不生效"。**直接比对 `RLProposer` 本体后确认算法是有区别的**:

```
idbd       α_mean=0.689  std=0.606   α∈[0.200, 1.662]
idbd-raw   α_mean=0.259  std=0.063   α∈[0.200, 0.382]
autostep   α_mean=0.097  std=0.020   α∈[0.068, 0.124]
cidbd      α_mean=8.210  std=3.776   α∈[0.200, 10.000]   ← 顶到截断
```

`cidbd` 顶到截断 `α_max=10` 是**已知失效模式**(此前 regime-shift 消融里
`a_med=10.000` 同病)。`oak_diag.sh` 的 D3 用修好的统计重跑。

## 4. 为什么有害 —— 诊断实验(**已完成, 结论明确**)

主结论是负面且显著的,所以**必须查清原因**,不能停在"没用"。
三个假设各配一个可判定的实验:

| 假设 | 实验 |
|:--|:--|
| H1 option 执行 = 提交固定动作序列 → 减少自适应性 | D1 `--opt-frac` 剂量-反应 |
| H2 option 执行降低探索多样性 → 覆盖度更窄 | D1 同上 |
| H3 option 从**过期的**转移模型中发现 | D2 `--oak-refresh` 2/8/16 |

### D1 剂量-反应:**伤害随 option 使用量放大 → 支持 H1/H2**

| opt_frac | any-time (n=3) | option 步数 | Δ vs E9 | p |
|:--|:--|:--|:--|:--|
| **0.0** | **0.7604 ± 0.0020** | 0.0 | **+0.0018** | 0.344 |
| 0.25 | 0.7560 ± 0.0008 | 25.3 | −0.0026 | 0.096 |
| 0.5 | 0.7488 ± 0.0019 | 45.3 | −0.0098 | **<0.0001** |
| 1.0 | 0.7506 ± 0.0038 | 61.3 | −0.0080 | **0.0025** |

(参照 E9 无 Options:0.7586 ± 0.0047, n=10)

- **哨兵通过**:`opt_frac=0.0` 与 E9 **一致**(p=0.344)→ 诊断实现本身可信。
- **剂量-反应**:frac 与 any-time 的相关系数 **r = −0.801**。
- **→ 问题出在 option 执行本身**(提交一段固定动作序列,减少自适应性与探索
  多样性),**不是** discovery 过程在扰动状态。

**★ 必须说清的非单调性**:0.5(0.7488)比 1.0(0.7506)略低,`r=−0.801` 主要由
端点驱动;0.5 vs 1.0 的差在 n=3 下**不可分辨**(std 0.0019–0.0038)。
诚实表述是「**伤害从 0→0.5 递增后进入平台**」,不是完美线性剂量-反应。

### D2 世界模型新鲜度:**越新鲜越好 → 支持 H3(但为次要因素)**

| refresh | any-time (n=3) | 最差遗忘界 | 发现的 options |
|:--|:--|:--|:--|
| **2** | **0.7511 ± 0.0012** | 0.3808 ± 0.0423 | 7.7 ± 1.5 |
| 4(默认) | 0.7467 ± 0.0058 | 0.3366 ± 0.0615 | 7.4 ± 3.0 |
| 8 | 0.7444 ± 0.0062 | 0.3792 ± 0.0848 | 8.7 ± 0.6 |
| 16 | 0.7437 ± 0.0013 | 0.3517 ± 0.0653 | 8.0 ± 1.7 |

**单调:重建越频繁越好 → 过期结构确实有害(H3 成立)。**
**但即使 `refresh=2`(0.7511)仍低于 E9(0.7586)** —— 所以**陈旧只是次要因素,
主要伤害来自 option 执行本身**(与 D1 一致)。

### 诊断综合结论

```
Options 有害 =  主要: option 执行本身 (H1/H2, 提交固定动作序列)
             +  次要: 从过期世界模型中发现 (H3)

两条证据独立且方向一致:
  D1  伤害随使用量从 0→0.5 递增 (r=-0.80, frac=0.0 哨兵与 E9 一致)
  D2  重建越频繁越好, 但最佳情形仍打不赢 E9
```

**这不是实现 bug,而是机制本身的性质** —— 至少在本任务(动作 = 选细区间训练,
状态 = 能力画像,reward = Δ any-time)上是如此。

## 5. 实验边界(必须明说)

- **没有真实 actuator**。本工作是 **predictive / control-policy learning on
  passive observations**,外加**离线 / 模型内反事实**验证。
  **不能**写成"完成了磁通控制实验"。
- 数据是 NASA CDAWeb 的真实空间物理观测(Van Allen Probes),不是可控仿真。
- regime shift 用的是**动作→物理区映射的置换**,是一个**受控代理**,
  不是数据源本身的变化(真数据切换需要改加载路径,列为未来工作)。
