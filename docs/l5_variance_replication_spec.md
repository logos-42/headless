# 方差效应的独立复现 —— 事前注册规格

**写下时间**: 2026-09-29,在**任何数据产生之前**
**待复现的发现**: `docs/l4_verdict.md` §3
**上游**: L4(n=29,`--stream revisit`)发现三个闭环 option 档的跨 seed 方差
约为无 option 基线 `e9` 的 **1/3~1/4**(sd 0.0258 → 0.0124/0.0135/0.0150),
F 检验 p ≤ 0.005,自助法方差比 95% CI 全部排除 1。

> **为什么必须复现**: 那条发现是**事后**看到的(我们本来在找均值差异)。
> 事后发现属于**假说生成**,不属于确证。在它进入论文之前,必须在一个
> **事前指定的独立设置**上重新检验一次。

## 1. 独立设置(只改一个变量)

| 项 | L3 / L4(原发现) | **L5(本复现)** |
|:--|:--|:--|
| `--stream` | `revisit` | **`nonstationary`** |
| 数据 / 特征 | RBSP-A,wfr-bands 13,lshell,pool cat | **逐字不变** |
| `--backbone/--norm/--cl-method` | mlp / fixed / replay | **逐字不变** |
| `--epochs-per-domain` | 100 | **逐字不变** |
| `--rounds` | 300 | **逐字不变** |
| `--domains` | 6 | **逐字不变** |
| `--proposer / --oak-gate / --oak-refresh` | oak / 1 / 4 | **逐字不变** |

**为什么选 `nonstationary` 而不是 `perm`**: 读代码确认(`run_lm4_wave.py:685-688`)
`perm` 只生成 6 个域的**一个置换然后重复 50 次** —— 那是高度平衡、低方差的调度,
会让复现更难而不是更独立。而 `revisit` 已经是每轮 `randint` 抽域。
`nonstationary` 用**正弦漂移权重**(`:689-697`)生成域序列,是完全不同的调度机制,
并且更贴近本项目关心的非平稳环境。**改动仅此一项。**

## 2. 臂集与样本量

| 项 | 值 |
|:--|:--|
| 臂 | `e9`(基线) / `goal` / `goal_term` / `goal_term_override` |
| 新 seed | **28…41 与 43…46(18 个)** —— 刻意跳过 **42**(L3 用过),且与 L4 的 `2…27` 无交集 |
| run 数 | 4 × 18 = **72** |
| 预估耗时 | 72 × 10.6 min ≈ **12.7h** |

**为什么 n=18**: 方差检验的近似功效 —— `z = log(方差比) / sqrt(4/(n-1))`。
若真实方差比 = 4(原发现的量级),`n=18` 给出 `z = 2.86 > 2.80` ⇒ **功效 ≈ 0.81**。
若真实方差比只有 2(减半),`n=18` 功效仅 ≈ 0.37 —— **事前承认这一点**,
届时以**方差比的置信区间**为交付,而不是以显著与否为交付。

**保留 `goal` 的理由**: `goal` 是"闭环但无 β_o"。它在 L4 上也显示了方差降低
(F=2.97),所以它能把**机制问题**分开:方差降低来自"有 option 层"本身,
还是来自 β_o 区域终止?这是次要假说 H2b。

## 3. 事前假说与判定规则

### H1(均值,次要)—— 闭环档与基线在均值上不可区分

对 `goal_term` 与 `goal_term_override`,与 `e9` 配对比较:
- `|Δ| < MDE` ⇒ **一致**(与原发现同向)
- `|Δ| ≥ MDE` 且 95% CI 排除 0 ⇒ **不一致**(原发现在新设置不成立,需报告)

### H2(★ 方差,主要)—— 闭环档的跨 seed 方差低于基线

**判定量**: 方差比 `R = var(e9) / var(臂)`

| 结果 | 条件 |
|:--|:--|
| **复现** | `goal_term` 与 `goal_term_override` **两个都**满足:F 检验 p<0.05 **且** 自助法 95% CI 下界 > 1 |
| **部分复现** | 只有一个满足 |
| **未复现** | 两个都不满足 |

**自助法**: B=20000,重采样各臂独立,报 `R` 的 95% 分位区间。

### H2b(次要,机制)—— 方差降低是否依赖 β_o

看 `goal`(无 β_o)的 `R`:
- `goal` 也显著 ⇒ 方差降低来自 **option 层本身**
- `goal` 不显著而 O3/O4 显著 ⇒ **β_o 是必要条件**

### H3(★ 天花板检查,否决条件)

**在解释 H2 之前必须先过这一条**:
- **作用域 = `e9` + H2 的比较臂(`goal_term`, `goal_term_override`)**,不含 `goal`
  (它是 H2b 的机制对照,均值天然更低)与 `fixed`(已判定档且 n=5)。
- 条件:这组均值彼此接近(极差 < 0.02)**且** 远离指标上限(距 1.0 至少 0.10)。

若不过 ⇒ **方差降低是饱和伪影, H2 判为无效**,无论 p 值多小。

> **2026-09-29 修订(在 L5 任何数据产生之前)**: 初版只写了"各臂均值必须彼此接近",
> 未写作用域。用 L4 数据验证判定脚本时,把 `goal` 与 `fixed` 一并算入会让极差
> 变成 0.0444 —— 但那反映的是"`goal` 确实有害"与"`fixed` 样本不足",不是
> "被比较的臂可比性"。故**明确作用域**。
> **本修订只改作用域的写法,不改任何判定阈值,也不改任何已测数字**;
> 它发生在 L5 数据存在之前, 因此 L5 的事前注册性完整。**留痕备查。**
>
> 另: 方差比在 `n < 8` 时自助法区间宽到无信息(实测 `fixed` n=5 → `[0.01, 24.81]`),
> 故判定脚本对 `n < 8` 的臂**拒报方差比**, 判为不可用。

### 否决条件(事前写死)

1. `goal_term` 或 O4 的**机制闸门**(`analyze_k1v2.py`)不过 ⇒ 该档对照无效
2. H3 不过 ⇒ H2 无效
3. 若方差比的自助法区间**包含 1** ⇒ 不得声称方差降低,只能报区间

(例如"方差比 < 1.5"),这比"没看到"强。**不许把 inconclusive 写成"无差异"。**
