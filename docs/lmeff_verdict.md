## 0. 一句话

**`replay`(复习旧域)在"重遇到同一个域时还记不记得"这个维度上有**巨大且逐 seed 一致**的优势(重访起点已达标比例 0.47 → 0.87);但我的主判据 `retention_gain` 在换锚点后塌成 +0.001 ⇒ **原判据作废, 效应改由无锚点的口径承载**。**

## 1. ★ 先说被推翻的东西:主判据 `retention_gain` 是锚点伪影

原口径 `retention_gain[d] = mean(start_level[k≥2]) − start_level[1]`:

```
                     naive     replay       Δ       逐 seed 全为正?
D0                  -0.0942   +0.4407   +0.5349
D1                  +0.4742   +0.7841   +0.3099
D2                  -0.1462   +0.4766   +0.6228
D3                  +0.1395   +0.4465   +0.3070
D4                  -0.0726   +0.5241   +0.5966
D5                  +0.1858   +0.3765   +0.1907
--------------------------------------------------
汇总 Δ = +0.4270   自助法 95% CI [+0.2433, +0.6135]   15/18 域更好
```

**看起来极强 —— 6/6 域同向、CI 不含 0。但它是假的。**

换锚点的稳健性检查:

| 锚点口径 | naive | replay | Δ | 逐 seed 全为正 |
|:--|--:|--:|--:|:--|
| `orig` 用第 1 次访问当锚 | +0.0811 | +0.5081 | **+0.4270** | **False** |
| `med3` 用前 3 次的中位数当锚 | +0.1317 | +0.2123 | +0.0807 | False |
| `slope` 对访问序回归(**完全不用锚**) | +0.0028 | +0.0038 | **+0.0010** | False |

**Δ 从 +0.427 塌到 +0.001。**

根因: `start_level[1]` 是**一个单点观测**, 而且它的值取决于"第一次遇到这个域时, 全局模型已经训到什么程度" —— 这是**随机**的。看原始数:

```
D0 naive  k=1 起点:  seed101 → 0.011 | seed202 → 0.755 | seed303 → 0.889
D5 naive  k=1 起点:  seed101 → 0.937 | seed202 → 0.002 | seed303 → 0.000
```

**同一个域、同一个臂, 三个 seed 的锚点从 0.011 到 0.889。** 拿它当分母, 效应大小基本由这个单点的运气决定。
"6/6 域同向"是这个噪声被系统性放大的结果(**replay 的锚点通常也低**, 因为两个臂的模型状态不同 ⇒ 差值不抵消)。

> **教训(同型第 N 次)**: 一个统计量只要靠**单个观测**当锚, 它就必须在**换锚点后**重算一遍。
> "换锚点后消失的效应"和"一开始就没测到效应"是**两个不同结论**, 前者要写进论文当缺陷。
> 这次是在**写结论之前**查出来的 —— 因为冒烟测已经教过一次"度量会打到地板"(见 §4)。

## 2. ★★ 站住的结论

### 2.1 主判据:重访起点"已经达标"的比例(`already_ratio`)

`already` = 该次访问**第一个采样点**的准确率 ≥ 该域可达上限 × 阈值(50%/90%)。
这是**约 300 次访问**的均值(**完全不依赖第 1 次访问**)。

| seed | arm | already | none |
|--:|:--|--:|--:|
| 101 | naive | 0.480 | 0.482 |
| 101 | **replay** | **0.887** | **0.057** |
| 202 | naive | 0.493 | 0.437 |
| 202 | **replay** | **0.860** | **0.082** |
| 303 | naive | 0.425 | 0.492 |
| 303 | **replay** | **0.857** | **0.075** |
| — | naive 均值 | **0.466 ± 0.0296** | 0.470 ± 0.0239 |
| — | replay 均值 | **0.868 ± 0.0134** | 0.071 ± 0.0106 |

```
Δalready(replay−naive) 逐 seed: [+0.407, +0.367, +0.432]   全部为正 ✓
Δnone   (replay−naive) 逐 seed: [-0.425, -0.355, -0.417]   全部为负 ✓
```

**两条都满足项目的可靠性标准 `std < mean/2`**(naive already: 0.0296 < 0.233; replay: 0.0134 < 0.434)。

**解读(这是本批最干净的一句话)**:
> 用 `replay` 时, **87% 的重访一上来就达到阈值**;不用时只有 **47%**。
> 等价地:**不着手复习的话, 超过一半(53%)的重访连该域 50% 的水平都够不着** —— 也就是"基本忘了"。

### 2.2 绝对口径:起点水平全程差 0.29–0.35

不依赖任何锚点(`前 10 次访问起点均值` vs `末 30 次`):

```
naive   前10次 0.404  →  末30次 0.483     (+0.079)
replay  前10次 0.692  →  末30次 0.829     (+0.171)
```

**两个臂的起点都在涨(全局进步, 这部分与 CL 无关), 但 `replay` 从头到尾高出一大截。**
而且差距**在最早就存在**(前 10 次:0.404 vs 0.692)⇒ rehearsal 不是靠后期累积起效的。

### 2.3 更新的方向性(`within_gain` / `slope_early`)

```
naive  within_gain 均值 -0.01047 (n=900) | slope_early -0.000136
replay within_gain 均值 +0.00852 (n=900) | slope_early +0.000141
```

`naive` 每次访问平均**净退步**(−0.0105),`replay` 净进步(+0.0085)。**符号相反, 但绝对值都很小** —— 因为绝大多数访问起点已经很高, 可涨的空间本来就小。**这一条只能当方向性旁证, 不能单独当结论**(它同样没有 CI)。

## 3. 未决的混淆(必须写清, 不能当"抗遗忘"直接下结论)

**`replay` 的总算力更大。** 本批的对照是 `naive`(不复习) —— 这是 CL 文献的标准对照,
但 `replay` 每步额外吃了一份旧域数据 ⇒ **它可能只是"训练得更多 / 正则化更强", 而不是"针对性地抗遗忘"。**

**判别性对照(下一步, 必须做)**:
```
臂 R  : replay              —— 复习**即将被遗忘的**旧域          (现有)
臂 Rr : random rehearsal    —— 复习**随机**旧域, 同样额外算力     (缺)
臂 Rz : zero rehearsal      —— 不复习, 但把同样的算力花在新域上   (缺)
```
- 若 `Rr ≈ R` ⇒ 效果来自**正则化/容量**, 不是抗遗忘 ⇒ **本结论必须降级**
- 若 `R ≈ Rz > Rr` ⇒ 是**针对性的**抗遗忘 ⇒ 结论成立
- 若 `Rz ≈ R` ⇒ 只是"更多梯度步"

**没有这三条, §2 只能写成"复习旧数据显著改善重访起点", 不能写成"抗遗忘"。**
