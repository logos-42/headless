## 三、分化性的实测机制(这部分是真知识)

### 逐分量诊断 (`tests/diag_stepsize.py`)

| | IDBD | Autostep(逐分量) | Autostep(全局) |
|:--|--:|--:|--:|
| `\|h\|` max/min | 4.08 | **72.11** | 58.64 |
| 指数 `\|e\|` max | 2.0(无上界) | **≡ μ** | **≡ μ** |
| alpha max/min | **26489** | **1.10** | **1.03** |
| h 自身相对离散度 | 0.448 | **1.157** | 1.164 |
| **alpha 相对离散度** | **1.645** | **0.032** | **0.010** |

**机制**: `h` 在 Autostep 里分化得**比 IDBD 更强** → **不是特征不可分**;但 alpha 几乎不分
→ **逐分量归一化抹掉了跨分量的量级差异**。`|e|max ≡ μ` 是直接证据:
归一化把每个分量的指数上界统一到 μ,只剩符号差异。

### Autostep 的「免调参」成立,但代价是放弃分化

`auto`(论文默认 μ=1e-2, α₀=0.1)与 `auto2`(μ=0.05, α₀=0.2)表现几乎相同(差 0.0022)
→ **免调参成立**;但两档的 alpha 分化都极弱(0.0004 / 0.0017)。

### 论文原始基准 (weight-flipping) 上两者都正常

| | IDBD | Autostep |
|:--|:--|:--|
| 分化成功 | 4/8 档 | **6/8 档** |
| **发散 (MSE ~1.6e9)** | **3/8 档** ⚠️ | **0/8 档** ✅ |

**单位分析**(Autostep 论文 §3)解释了 IDBD 的 μ 敏感: 指数 `δ·x·h` 量纲是 **y²**,
故最优 μ 量纲是 **1/y²**。我们的 reward ≈ 0.02 → 所需 μ 比 O(1) 目标大 ~2500 倍。
这解释了实测: α₀=0.01/0.05 时步长死亡(`alpha_std≈1e-6`),α₀=0.2 才活。
**与 V35.2/3 的 `β_std=1.6e-05` 是同一现象在两处的独立复现。**

## 五、我这轮犯并纠正的六个错误

| # | 错误 | 症状 | 修正 |
|:--|:--|:--|:--|
| ① | `--rl-algo/--rl-mu/--rl-alpha0` **只加签名和 CLI,调用点没接** | 四臂全报同一 algo;不同超参给出**逐位相同**结果 | 调用点补参数 + 断言回读 |
| ② | `probs()` 的 `exp` **下溢成恰好 0** | `ValueError: Fewer non-zero entries in p than size` | `np.clip(..., -30, 0)` + 均匀兜底 |
| ③ | 我误删 IDBD 官方式里的 `x` | 官方 Algorithm 4 是 `β += θ·δ·x·h` | 回滚 |
| ④ | **跨实现比较** | 得出「Autostep 结构上不累积」的**错误结论** | 统一走模块本体重测 → 全部算法都累积 |
| ⑤ | 加 RMS 归一化「安全化」IDBD | 真实回路 alpha_std 从 0.2357 → **0.0006**;原因是**双重归一化**(δ 已被 delta_rms 归一化,再除 grad_rms) | 提供 `idbd-raw`(不做 running 归一化) |
| ⑥ | **`idbd-raw` 未加进 CLI `choices`**;且 driver 里 `echo "... $(date) ... rc=$?"` **`$(date)` 先执行会重置 `$?`** | 6 个 run 全部失败却报 **`rc=0`** | 补 choices;rc 先存变量再 echo |
| ⑦ | `final_idbd_stats.py` 里 `def welch` 但调用写 `wl` | 运行时 NameError | LSP 抓到,改名 |
| ⑧ | **池化不同代码版本做检验** | 得出 p=0.0049 的假显著 | 撤下;按版本分开 + 补 seed 后 p=0.56 |

**教训(已固化)**: ①「加了参数/写了代码」≠「参数真的生效」,必须**回读验证**;
②**rc 必须 `RC=$?` 先存再 echo**(命令替换会重置 `$?`);
③**跨实现/跨版本的度量不能池化**;
④**n<5 的方向性结论不可信**(本轮 −24% 在 n=11 缩到 −6.2%)。
