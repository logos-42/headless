## 1. 一句话

> 在 deterministic `KeyDoorMDP` 上 **A 类与 novelty 不可分辨**;
> 造出可辨识环境(E2)之后, **A1 在"熟悉但变了"的状态上响应 4.4 倍, 而新颖度控制量平坦** ——
> **A 类具有可辨识性**, 但当前实现有两个必须修的实现缺陷(见 §5)。

---

## 2. 为什么需要 A′(不是"加噪声让 A 类通过")

原环境的病是**信息论上的**, 不是调参能修的:

| 量 | 在原 KeyDoor 上的值 |
|:--|:--|
| `H(T\|S,A)` | **逐位 0.000000**(实测所有 `n>=2` 的 `(s,a)`) |
| `step()` 随机源 | **无** |
| 结论 | `预测误差 ≈ 不确定性 ≈ 稳定区域 ≈ 计数` —— 三个语义不同的量**坍缩成同一个数** |

所以正确的问题不是"A 类准不准", 而是 **"这个 benchmark 有没有能力证伪 A 类"**。

## 3. 三个环境(A′-2)与一个被推翻的构造

| 环境 | 构造 | 结果 |
|:--|:--|:--|
| **E0** `KeyDoorMDP` | 确定性 | 负对照, 保留 |
| **E1** `StochasticKeyDoor` | 平稳随机 slip=0.10 | 无 shift 对照 |
| **E2** `NonStationaryKeyDoor` | slip 0.10→0.60 @ shift | ✅ **可用** |
| ❌ `FlipKeyDoor` | 支撑集不变, 只翻转分布 | **失败, 保留为反例** |

### ★ 被推翻的判断(值得单独记)

我原以为"翻转分布、不扩张支撑集"是最干净的 regime shift:

    P(s'|s,a) = (1-p)·1[s'=T(s,a)] + p·1[s'=T(s,c(a))]     支撑集恒为两点

推理:支撑集不变 ⇒ 到达的状态集合不变 ⇒ novelty 不变;而 `p̂` 错了 ⇒ A1 跳。
**实测相反**(探针③,逐步紧邻等长窗口):

    通道      E2 翻转        E2 slip↑      读数
    N        3.62 倍        0.88 倍       ← 翻转把 novelty 拉爆
    A1       3.39 倍        3.10 倍
    A2       2.75 倍        1.25 倍

> **决定 novelty 的不是转移的支撑集, 而是最终的「去向分布」。**

支撑集是"**可能**被到达", novelty 量的是"**实际**去过几次"。翻转在 90% 的步子上
把 agent 送到它几乎没去过的**伙伴目标** ⇒ 它真的闯进了新领地。
而均匀随机 slip↑ 是在**已熟悉的地盘内**增加不可预测性 ⇒ 访问分布不动, `p̂` 却错了。

**教训**:agent 的行为是**状态依赖**的 —— 改了动力学就改了轨迹, 改了轨迹就改了
访问分布。要抑制 novelty, 得直接让访问分布不变, 不能只让转移的支撑集不变。

## 4. 四象限(C4)+ 检测指标(C5)

### 4.1 主判据:n 对齐的 S1 → S3

★ **不能用 S2 vs S3。** S2 是**首次访问**步, 而 `_rr_dval` 在 `n<2` 时**返回满值 1.0**;
热身期到处是这种步 ⇒ S2 在所有通道上被顶到 0.7~0.8, 必然压过 S3。
第一版判定就是这么被污染的(`S2 各通道 [0.696, 0.786, 0.777, 0.517]`)——
那是**饱和分支**的指纹, 不是"A 类分不开新与变"的证据。

正确的对齐方式:取**同为熟悉**状态(`n >= 10`),只让动力学变。

```
E2 非平稳(shiftt@400), n 对齐的 S1 -> S3:
  A1   0.1046 -> 0.4550   (+0.3504)   4.4 倍
  N    0.0487 -> 0.0291   (-0.0195)   平坦
  A2   0.0567 -> 0.1976   (+0.1409)   弱于 A1
  A3   0.1513 -> 0.1953   (+0.0440)
```

**A1 在熟悉状态上对"变"敏感, 而纯新颖度控制量平坦。**
且 **A1(+0.3504) 明显强于 A2(+0.1409)** —— 这是 A 类候选**第一次**在同一环境上
表现出不同的量, 不再是同一个量的两份拷贝。

### 4.2 检测指标

```
通道    阈值     T_detect  延迟   FP     FN    AUC
N      0.2676    None     None   0.24   1     0.232    ← 检测不到
A1     0.5303     400        0   0.23   0     0.737    ← ★ 零延迟, FN=0
A2     0.1399     450       50   0.21   0     0.759
A3     0.7446    None     None   0.20   1     0.765    ← 检测不到
```

* **A1 零延迟检测**(`T_detect − T_shift = 0`, FN=0);N 完全检测不到。
* **但 FP ≈ 23%** —— 阈值被 shift 前 23% 的步跨过。**这是当前最大的缺口**。
* **AUC 与触发不一致**:A2/A3 的 AUC(0.759/0.765)反而高于 A1(0.737), 但 A3
  触发不了。⇒ AUC 量的是**排序可分性**, 触发量的是**绝对水平**, 两者不可互替。

### 4.3 阈值估计的一个坑

第一版用 `pre` 的 **95 分位**做阈值 ⇒ 被饱和的 1.0 撑到 **1.0000**, 而指标上限
就是 1.0 ⇒ **阈值不可达**, `T_detect` 全 `None`、`FN` 恒 1。
第二版改用 `μ+2σ`, 但仍然被饱和步污染(A1 阈值算成 **1.0680 > 1.0**)。
**正解:阈值只能从非饱和步(`n>=2`)估计, 并夹到 `[0,1]`。**

> 阈值不可达的指纹 = "所有通道阈值相同(1.0000)、全部 `T_detect=None`"。
> 这不是"检测不到", 是**判据根本开不了火**。

## 5. 裁定

| 门 | 判据 | 结果 |
|:--|:--|:--|
| ① 环境前提 | E0 熵恒 0;E1/E2 非平凡 | ✔ |
| ② 构型 II 前提 | shift 后同一批 `(s,a)` 熵上升 | ✔(128/128 全升) |
| ③ 构型 II 公平性 | `N` 不跳而 `A1` 跳 | ✔(0.88 vs 3.10) |
| ④ S1→S3 判别 | `A1` 在熟悉状态上响应 > +0.10 | ✔(+0.3504) |
| ⑤ A1 强于 novelty | `dA1 > dN + 0.10` | ✔(+0.3504 vs −0.0195) |
| ⑥ AUC | `A1` 的 AUC 高于 `N` > 0.10 | ✔(0.737 vs 0.232) |
| ⑦ 检测延迟 | `T_detect − T_shift` 有限 | ✔(0, FN=0) |
| ⑧ 假阳性 | `FP` 低 | **✘ 0.23** |

**结论:可辨识性成立(④⑤⑥⑦ 全过), 但假阳性率 0.23 未达可用标准。**

### 允许的表述 / 禁止的表述

* ✅ **允许**: "在 E2(非平稳随机 KeyDoor)上, 转移预测误差 A1 对动力学变化
  的响应显著强于纯新颖度控制量 N, 且变化发生在**已熟悉**的状态上。"
* ❌ **禁止**: "A 类是好 cumulant" / "A 类可以进阶段五多 GVF 合并"。
  **① 这是一个环境、一个 seed 的结论;② FP=0.23 使它在决策层不可用。**
