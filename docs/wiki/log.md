## 2026-09-27 (晚·续四) 在线可用势函数 = GVF; 退休必须可逆

**问题**: leo 问「在线可用的势函数怎么解决?」。**先探针后改码**, 探针抓到三层, 层层比上一层深:

1. **`Φ = max_a Q` 逐位等于初值**: 探针量出 444 次结算里 `V(s0) = 1.0000` 精确, `γ^k·V(s1) = 0.717`, `Q_adv ≡ −0.275`。根因不是"学得慢"是**结构**: `q_init=+1.0` 乐观初始化, **只要有一个动作没试过 `max_a` 就还是 1.0**。第二层: option 绕过 Q(靠模型 π_o 导航, 基元只在 fallback 用) ⇒ **势函数恰在最需要它的地方没学过**。
2. **正解 = GVF**: 中性初始化(全 0)状态价值表, TD 从**每个转移**学(无论谁出的动作), 不需要转移模型/目标坐标 ⇒ 无 oracle。同 regime 同 300 回合三源对比: `learned` Φ∈[0.85,1.0] 7 个值 advq −0.275; `exact`(oracle) Φ∈[0,1] 13 值 advq **+0.008/+0.009**; **`gvf` Φ∈[0,0.999] 15 值 advq +0.0495/+0.0356 —— 符号与 oracle 一致**。
3. **★ 退休会切断证据来源 ⇒ 任何判据都自我封闭**: 判坏→不用→统计量冻结→永远坏。实测 `Q_adv` 冻在 −0.0059, fallback 0.991, 两类故障输出**逐位相同**。修法不是调阈值是加**通路**: `rr_forgive_p`(被判坏者以 p 概率被重新检验), fallback 0.991→**0.397/0.276**, inert 故障随即被正确放过(T_adapt 20, 步数 ≈ uniform)。**「犯错是可以原谅的」= 退休可逆**。
4. **判据改为「上置信界 < 0」(显著更差)** —— 实测量到 `Q_adv = −0.0002` 落在噪声内, 严格 `<0` 会误杀; 且不需手工 ε(尺度由数据方差给出)。
